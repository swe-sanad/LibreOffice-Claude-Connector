# v0.9.5

The last release you saw was v0.9.2. This one is a big jump — it makes Claude a much
easier, safer collaborator when it's driving your LibreOffice documents through the MCP
server (Claude Desktop / Claude Code / Cowork).

## What you can do now

**Claude focuses on the tools that matter.** Under the hood there are 183 tools, but
Claude only sees 44 of them by default — the ones an everyday person actually reaches
for. The rest are still fully available; Claude just fetches them on demand instead of
having all 183 competing for attention on every single message. That's about a 74%
cut in the background "noise" Claude has to wade through before it even answers you.
If you're a power user and want everything visible up front, tick **"Advertise all
tools"** in the extension settings.

**One Ctrl+Z undoes the whole thing.** Previously, an action that touched many cells
could leave you undoing one cell at a time. Now most edits are grouped, so a single
Ctrl+Z in LibreOffice reverts the whole operation Claude just performed.

**New everyday tools**, aimed at things people actually ask for:
- `calc_overview` — a quick, readable summary of a spreadsheet instead of a wall of cells.
- `calc_format_table` — make a table look presentable (headers, borders, column widths,
  frozen header row) in one shot.
- `calc_clean_data` — trim messy whitespace, fix numbers that got stuck as text, drop
  blank rows.
- `calc_import_csv` — pull a CSV straight into the sheet you already have open.
- `calc_detect_errors` — find every broken formula in a workbook at once.
- `writer_format_document` — clean up a document's fonts, spacing and margins.
- `list_recent_documents` — "open the file I was working on" now works without you
  giving a path.
- `print_document` — send a document straight to your printer.
- `writer_resolve_comment` — mark a Writer comment resolved.
- `writer_captions` — see and reword existing captions (including ones you made by
  hand in LibreOffice), with the caption numbering staying correct.
- `writer_insert_caption` can now attach a caption directly to a named table or image
  (captions land above tables, below figures, matching normal convention).

**Better recovery when something goes wrong.** New tools let Claude check LibreOffice's
health before doing anything risky (`lo_health`), recover from a prior crash without you
having to click through LibreOffice's own recovery dialog (`lo_recover`), and take a
snapshot of a document it can roll back to if an edit goes wrong (`checkpoint_document`).

**No more silent hangs.** If a LibreOffice dialog box was left open, Claude used to just
wait forever with no explanation. Now every call times out (120 seconds by default,
adjustable) and Claude gets told what likely happened instead of going quiet.

**Clearer errors.** When something fails, Claude now gets a reason and a hint for what
to try next, instead of just a raw error it has to guess about.

**No separate download for the add-on.** Claude can normally only reach a LibreOffice it
started itself. A small add-on fixes that, letting it work with a document you already
have open — and that add-on now ships *inside* this download instead of being a separate
one. You still install it once (ask Claude to run `lo_status` and it will hand you the
exact one-line command, with the file already on your machine), then restart LibreOffice.

## Please read this: a real undo limitation

There's one thing Ctrl+Z genuinely cannot fix. When Claude replaces a whole block of
spreadsheet cells at once (`calc_write_range`, and the number-cleanup part of
`calc_clean_data`), LibreOffice logs an undo entry that *looks* normal in the Edit menu,
but pressing Ctrl+Z does **not** restore the old values — the cells stay changed.

This is a real limitation in LibreOffice itself, not a bug we can quietly patch around.
The fix is `checkpoint_document`: ask Claude to take a checkpoint before a big bulk
edit, and you can roll all the way back to it if the result isn't what you wanted. We
verified this works — we deliberately destroyed data with a bulk write, confirmed
Ctrl+Z couldn't bring it back, then restored it from a checkpoint.

## Upgrading

Because this version number (0.9.5) is lower than a build number some of you may
already have installed, Claude Desktop may refuse to install it as an "update." If that
happens: remove the existing LibreOffice Connector extension first, then install this
`.mcpb` fresh.

## Verified

- 128 offline tests pass.
- Everything in this release was exercised against a real LibreOffice 25.2.3.2 with its
  bundled Python 3.10.17 — not just mocked.
- The checkpoint-rollback behavior above was verified live: data destroyed by a bulk
  write, confirmed non-recoverable by Ctrl+Z, then restored from a checkpoint.
