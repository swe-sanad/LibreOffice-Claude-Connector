# v0.9.7

v0.9.6 taught the server to carry a document from a blank page to a finished file. This
one adds the missing question at the end of that journey: **"what's still wrong with
it?"**

## What's new

**One call to find what a document needs before you send it.** The new
`diagnose_document` is the read-only health check for the open document — the Writer
counterpart of `calc_detect_errors`. It builds on the same lifecycle facts
`document_lifecycle` already gathers, then reports the structural problems worth
fixing, each pointing at the tool that fixes it:

- **Pseudo-headings** — short, fully-bold body paragraphs dressed up as headings that
  never reach the navigation, the table of contents, or the PDF outline (→ `writer_apply_style`).
- **Broken cross-references** — a reference field whose target is no longer a bookmark,
  reference mark, or caption sequence (→ `writer_insert_cross_reference`).
- **Missing image alt text** (→ `set_alt_text`), **unfilled placeholder fields**
  (→ `writer_replace_selection`), and leftover **TODO/FIXME** markers in the body.
- For Calc, every **broken formula cell** across all sheets (→ `calc_set_formulas`).

It returns `{kind, summary, issues:[{type, severity, where, fix}]}` and is advertised in
the everyday tier, so a "check this document" pairs naturally with `document_lifecycle`'s
"where does it stand." Verified end-to-end against a real LibreOffice (a document with an
un-alt'd image and a broken cross-reference is correctly flagged with both fixes named).
