# v0.10.0

A minor release that closes [#15](https://github.com/swe-sanad/LibreOffice-Claude-Connector/issues/15):
**Writer in-place editing without `uno_exec`.** 218 → 220 tools, 74 advertised.

The trigger was a real session: an agent restructuring a 3-page CV in place gave up on the
discrete tools and wrote one UNO script. Root-causing why produced nine gaps. All nine are
closed, and the issue's acceptance scenario — read with detail → checkpoint → delete a span
including its tables → insert an 80-paragraph block with markup and the document's own bullet
style → tab stops → page map → export — runs with zero `uno_exec` calls. It is exercised live
against a headless LibreOffice by `tests/integration/test_writer_inplace_uno.py`.

## Fixed

**`dispatch list` only ever showed 16 tools.** Every tool module defines its own `TOOL_DEFS`,
and that name shadowed the registry's under the star import — so the catalog listed just the
`shared_automation` module. Agents reasonably concluded the other 200 tools did not exist and
dropped to scripting. The catalog now lists **every** registered tool, grouped by application
(`writer` / `calc` / `impress` / `draw` / `document` / `server` / `escape-hatch`), one line
each, with an `advertised` flag, and accepts `filter` (`"writer"`, or a substring such as
`"paragraph"`). A regression test compares it against the registry.

**`set_alt_text title=…` raised unless the title was a substring of an open document's
title.** It routed its args through the document selector. Fixed, and it gained `url` for
linked logos.

## Added

| Tool | What is new |
|---|---|
| `writer_insert_paragraphs` (new, advertised) | insert a styled block before `at_index`: text, style, `list` (bullet / number / an existing numbering style), level, spacing; markup on by default; returns `next_index` |
| `writer_page_map` (new) | where the page breaks fall over body paragraphs |
| `writer_append_text`, `writer_insert_heading` | `at_index` (insert before a paragraph), `markup` |
| `writer_set_paragraph_text` | `markup` |
| `writer_format_text` | `start`/`count`, `char_start`/`char_end`; `search` no longer required |
| `writer_format_paragraph` | `font_size`, `font_name`, `bold`, `italic`, `font_color`, `keep_with_next` |
| `writer_apply_list` | `list_style`, `level`, `copy_from_index` — match the document's own bullets |
| `writer_get_paragraphs` | `start`/`count`; `detail` → numbering, spacing, keep_with_next, tab stops, runs (bold/italic/size/color/url), anchored images; `total` |
| `writer_list_figures` | `anchor_index`, `url`, `title`, `description` |
| `writer_delete_paragraphs` | `include_tables` |

Inline markup is deliberately small: `**bold**`, `*italic*`, `[text](url)`. No nesting, no
escaping; an unclosed marker stays literal.

## Install

Claude Desktop: download `libreoffice-connector-0.10.0.mcpb` from the release and open it.
The bundled `.oxt` is unchanged in behaviour but carries the same version number.

## Known

`tests/integration/test_mcp_tools_extended.py` still references private helpers that moved
into tool modules in 0.9.8 and fails after its Calc section — pre-existing, listed in
`docs/KNOWN-GAPS.md`. The Writer tools this release touched are covered by the new test.
