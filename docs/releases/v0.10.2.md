# v0.10.2

A patch release focused on RTL/CTL typography, Calc formula normalization, Writer table styling, lifecycle reliability, and full tool visibility. 220 → 222 tools, all 222 advertised.

## Fixed

- **RTL/CTL font and direction handling:** Fixed RTL/CTL typography and text direction behavior across Writer tools (`6aa5e18`).
- **Calc formula normalization:** Normalized formula separators and argument handling across locales (`6aa5e18`, `a6ba47c`).
- **`document_lifecycle` with no document open:** Handled `no_document` states cleanly instead of failing when no document is currently active (`6aa5e18`).
- **`list_documents` & `lo_status` reliability:** Routed `list_documents` through a shared core helper (`05255dc`) and kept document titles JSON-safe in `lo_status` when a chart is open (`1897fd0`).
- **PR #17 fixes:** Merged PR #17 improvements (`ad6c85d`).
- **Offline `tools/call` tests:** Kept `tools/call` tests offline and updated the reconnect test for `arg_sep` (`a6ba47c`).

## Added / Changed

- **All 222 tools advertised:** Added all 222 tools to `BASIC_TOOLS` so every registered tool is advertised directly to MCP clients without needing `dispatch` discovery (`e48f2d0`).
- **Writer table styles:** Added/updated table style support (`6aa5e18`).
- **Documentation:** Regenerated `docs/MCP-TOOLS.md` for v0.10.2 (`ebbb68a`, `e48f2d0`) and updated project name in `README.md` (`201d292`).

Claude Desktop: download `libreoffice-connector-0.10.2.mcpb` from the release and open it.
